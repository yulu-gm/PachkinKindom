- 初始画面显示 56 个均匀 grid 钉位，发射轨道顶部入口保持开放。

- 单位球能从右侧封闭发射轨道进入场地；返回发射起点时可点击补力。
- 每次撞钉显示 `+10 EXP`；升星和进化显示居中横幅与镜头反馈。
- 球从底部统一出口进入发光转移轨道，多球依次到位，最后一球到位后自动战斗。
- 战斗中攻击方播放攻击动画，受击方播放受击动画，并显示弹道、爆点、伤害数字与护盾反馈。
