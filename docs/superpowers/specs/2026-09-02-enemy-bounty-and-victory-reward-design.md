# 敌人赏金与胜利奖励设计

## 目标

让敌人赏金同时体现形态阶级和星级，并为每场战斗胜利提供固定奖励。

## 敌人赏金

公式：

`敌人赏金 = 5 + 形态阶级 + 星级额外金币`

形态阶级沿每条五阶职业链从 0 到 4：

- 第一形态：+0
- 第二形态：+1
- 第三形态：+2
- 第四形态：+3
- 第五形态：+4

星级额外金币：

- 一星：+0
- 二星：+3
- 三星：+5

不设置额外封顶。因此赏金范围为 5～14 金币。

示例：

- 一星战士：5
- 一星骑士：6
- 二星骑士：9
- 三星将军：12
- 三星领主：14

## 胜利奖励

玩家赢得战斗时，在全部敌人赏金总和之外额外获得 5 金币。最终关卡胜利同样获得该奖励。战斗失败不结算赏金或胜利奖励，因为失败会直接结束本局。

`战斗总奖励 = 敌人赏金总和 + 5`

## 实现与验证

- 保留现有形态阶级映射，移除 8 金币封顶。
- 使用星级额外金币表 `{1:0, 2:3, 3:5}`。
- `stageReward` 统一加入 5 金币胜利奖励，所有胜利路径继续复用该函数。
- 控制器测试覆盖不同形态与星级组合、无封顶、普通关卡和最终关卡奖励。
