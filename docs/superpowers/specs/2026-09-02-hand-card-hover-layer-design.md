# 手牌 Hover 顶层预览设计

## 目标

鼠标悬停或键盘聚焦手牌时，将卡牌的放大预览浮动到手牌滚动区之外的顶层，使卡牌顶部始终完整可见，同时不影响横向滚动、卡牌排序和拖放操作。

## 问题原因

手牌列表需要使用 `overflow-x: auto` 支持大量卡牌横向滚动。浏览器会因此同时建立裁剪区域，卡牌即使提高 `z-index`，向上放大后仍无法越过滚动容器边界。

## 方案

- 在手牌区中增加一个位于滚动列表之外的顶层预览容器。
- 悬停卡牌或卡牌获得键盘焦点时，在顶层容器中显示该卡牌的只读副本。
- 预览以原卡牌中心为基准定位，并在屏幕左右边缘进行位置约束，避免首张或末张卡牌横向溢出。
- 原卡牌继续留在列表内，不改变布局、顺序、滚动位置或拖放命中区域。
- 顶层预览不接收鼠标事件、不可拖动、无障碍树中隐藏；拖放仍从原卡牌开始。
- 指针离开、焦点移出、开始拖动、界面重绘或阶段切换时立即清理预览。
- 为手牌补充键盘聚焦能力；系统启用“减少动态效果”时取消预览动画。

## 状态与数据边界

顶层预览只复制卡牌的当前视觉内容，不写入卡牌状态，不调用游戏控制器，也不参与卡牌使用判定。它属于纯 HUD 展示状态，HUD 重绘时可直接丢弃并按需重建。

## 验收标准

- 悬停或聚焦第一张、中间和最后一张手牌时，放大卡牌均完整显示在最上层，顶部不被截断。
- 手牌区尺寸和游戏场地可视面积不发生变化。
- 大量手牌仍可横向滚动，预览不会引起布局跳动。
- 原有拖放、卡牌使用和已用牌堆交互保持正常。
- 预览不会阻挡鼠标操作，并支持减少动态效果设置。
