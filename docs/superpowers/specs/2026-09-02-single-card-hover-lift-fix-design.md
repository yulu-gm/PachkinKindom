# 手牌单卡上浮修正设计

## 目标

Hover 手牌时只显示并操作原本的那一张卡牌。卡牌上浮放大后不受横向滚动容器裁剪；鼠标离开后立即回到手牌，不因鼠标点击留下的普通焦点持续上浮。

## 根因

当前实现复制了一张只读卡牌到顶层，但仍显示原位置卡牌，因此产生双层画面。事件清理又把普通 `focus` 当成持续激活条件，鼠标移开后可能继续显示顶层卡牌。

## 设计

- 不再克隆卡牌。Hover 或键盘 `focus-visible` 激活时，将真实卡牌元素临时移动到手牌区的顶层容器。
- 移动前在原位置插入一个无内容、不可见的布局占位。占位只保存卡牌在扇形手牌中的宽度、负边距和顺序，不呈现卡面。
- 顶层中的真实卡牌保持原有 `data-card-id`、拖放属性和事件监听，因此拖放仍从同一张卡牌开始。
- 激活区域覆盖顶层卡牌和原位置占位，避免指针位于上浮前后的边缘区域时发生闪烁。
- 鼠标离开整个激活区域、开始横向滚动、界面重绘或阶段切换时，将真实卡牌恢复到占位位置并移除占位。
- 鼠标产生的普通焦点不会维持上浮；只有键盘导航产生的 `focus-visible` 可以在没有 Hover 时保持上浮。
- 顶层卡牌继续进行左右边缘约束，并遵循减少动态效果设置。

## 状态边界

上浮和占位仅是 HUD DOM 状态，不修改卡牌数据、使用状态、排序或游戏控制器。HUD 重绘前应先恢复卡牌；若重绘直接替换 DOM，则不保留任何上浮状态。

## 验收标准

- Hover 时 DOM 中始终只有一个带 `.hand-card` 的对应卡牌元素，画面中没有底层卡牌或双重边框。
- 鼠标移出后卡牌立即回到原位，不再自行上浮。
- 键盘 Tab 聚焦仍能上浮，焦点移走后恢复。
- 扇形手牌不因卡牌上浮发生挤压或跳动。
- 从上浮卡牌开始拖放仍然有效。
- 横向滚动、界面重绘和减少动态效果行为正常。
